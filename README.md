# Personal Homepage Template

This repository contains a static GitHub Pages personal academic homepage.

## Edit Your Information

- Homepage content: `index.html`
- Publications page shell: `publications.html`
- Publication records: `assets/data/publications.json` and `assets/data/publications.js`
- Awards page: `awards.html`
- Main styling: `assets/css/styles.css`
- Theme/menu behavior: `assets/js/main.js`
- Placeholder avatar: `assets/img/avatar.svg`

Replace `Your Name`, `your.email@example.com`, profile links, education, publications, service, and awards with your own information.

## Local Preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

Push this repository to GitHub. For a repository named `mxx0723.github.io`, GitHub Pages will serve it at:

```text
https://mxx0723.github.io/
```
